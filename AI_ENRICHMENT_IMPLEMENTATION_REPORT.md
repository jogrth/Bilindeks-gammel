# AI Enrichment Pipeline Implementation Report

## Overview
This report documents the implementation of a scalable AI-based enrichment pipeline that can automatically populate data for ANY car model, not just a predefined list.

---

## 1. HOW AI ENRICHMENT IS IMPLEMENTED

### Architecture

```
User Input (e.g., "Polestar 4")
    ↓
Batch Import API
    ↓
enrichModel()
    ↓
Check Known Database → YES → Use Curated Data (10 models)
    ↓ NO
AI Enrichment Service
    ↓
OpenAI GPT-4o-mini API → YES → Structured JSON Response
    ↓ NO (API unavailable)
Generic Fallback Data
    ↓
Database Update with Source Tracking
    ↓
Similar Cars Generation
    ↓
Complete
```

### Key Components

1. **lib/services/ai-enrichment.ts** (NEW)
   - `enrichWithAI()` - Main AI enrichment function
   - `callOpenAI()` - OpenAI API integration
   - `generateFallbackEnrichment()` - Generic fallback when API unavailable

2. **lib/services/enrichment.ts** (UPDATED)
   - Maintains known dataset for 10 models
   - Uses AI as fallback for unknown models
   - Tracks enrichment source and confidence
   - Handles trim levels if AI provides them

3. **Database Migration** (NEW)
   - `enrichment_source` enum field
   - `enrichment_confidence` numeric field
   - `enrichment_notes` text field

### Data Flow

```typescript
// Pseudocode
if (model in KNOWN_DATABASE) {
  source = 'known_dataset'
  confidence = 1.0
  data = CURATED_DATA
} else {
  if (OPENAI_API_KEY exists) {
    result = callOpenAI(brand, model)
    source = 'ai_generated'
    confidence = result.confidence (0.6-0.95)
    data = result.data
  } else {
    result = generateFallback(brand, model)
    source = 'ai_generated'
    confidence = 0.3
    data = GENERIC_TEMPLATE
  }
}
```

## 2. PROMPT STRUCTURE

### System Prompt

The AI receives a detailed system prompt with:

1. **Role Definition**
   - "You are a Norwegian electric vehicle expert"
   - Establishes context and expertise

2. **Output Format**
   - Strict JSON schema
   - No markdown, no explanations
   - Exact field structure required

3. **Data Requirements**
   ```json
   {
     "body_type": "SUV|Sedan|Stasjonsvogn|...",
     "drivetrain": "electric",
     "drive_type": "AWD|RWD|FWD",
     "seats_max": 5,
     "range_wltp_km": 450,
     "cargo_space_liters": 500,
     "towing_capacity_kg": 1500,
     "price_from_nok": 500000,
     "intro_text": "Norwegian description",
     "seo_content": {...},
     "faq_content": [...],
     "trim_levels": [...],
     "confidence": 0.85,
     "notes": "Warnings or clarifications"
   }
   ```

4. **Guidelines**
   - Use real 2024-2026 data if available
   - Realistic Norwegian pricing
   - Provide estimates if uncertain
   - All text in Norwegian
   - Factual and professional tone
   - 2-4 trim variants if known

### User Message

Simple format:
```
Enrich this car model: [Brand] [Model]
```

Example:
```
Enrich this car model: Polestar 4
```

### Temperature & Model

- **Model**: `gpt-4o-mini`
  - Cost-effective
  - Fast responses
  - Good for structured data

- **Temperature**: `0.3`
  - Low temperature for consistency
  - Reduces creativity/hallucination
  - More factual outputs

- **Max Tokens**: `2500`
  - Enough for full response
  - Prevents truncation

## 4. HOW UNCERTAINTY IS HANDLED

### Confidence Scoring

**Known Dataset**: 1.0 (100%)
- Manually verified data
- Accurate specifications
- No estimates

**AI High Confidence**: 0.85-0.95 (85-95%)
- Well-known recent models
- Data verified from multiple sources
- Minor estimates only

**AI Medium Confidence**: 0.70-0.84 (70-84%)
- Moderately known models
- Some specifications estimated
- Price may be approximate

**AI Low Confidence**: 0.50-0.69 (50-69%)
- Less common models
- Multiple estimates
- Needs verification

**Fallback Generic**: 0.30 (30%)
- No AI available
- All specs are estimates
- Requires manual review

### Notes Field

Examples of enrichment_notes:

```
"Data from curated database"
→ Known model, fully verified

"AI-generated with high confidence. Prices are for 2025 models in Norway."
→ AI, confident, recent data

"Range and cargo estimates based on segment. Verify with dealer."
→ AI, uncertain about specific values

"Limited data available for this model. Most values are estimates."
→ AI, low confidence

"Generic fallback data - OpenAI API not available. Values are estimates and should be manually verified."
→ Fallback used
```

### Admin UI Indicators

1. **Source Badge**
   - 🔵 Database (blue) = Verified
   - 🟣 AI (purple) = Generated
   - 🟡 Delvis (amber) = Partial
   - ⚫ Manual (gray) = Hand-entered

2. **Confidence Percentage**
   - Shown next to AI badge
   - Example: "AI 85%"
   - Helps prioritize review

3. **Notes Tooltip**
   - Hover over source badge
   - Shows enrichment_notes
   - Explains what's estimated

4. **Model Detail Page**
   - Dedicated "Data-kilde" section
   - Shows source type

         ↓
    Low confidence (<0.7)?
         ↓ YES

         ↓ NO

## 5. HOW ENRICHMENT SOURCE IS STORED

### Database Schema

```sql
CREATE TYPE enrichment_source_type AS ENUM (
  'known_dataset',   -- Curated database
  'ai_generated',    -- OpenAI or fallback
  'manual',          -- Admin entered
  'external_api',    -- Future: other APIs
  'partial'          -- Mixed sources
);

ALTER TABLE models ADD COLUMN
  enrichment_source enrichment_source_type DEFAULT 'manual',
  enrichment_confidence numeric(3,2) DEFAULT NULL,
  enrichment_notes text DEFAULT NULL;
```

### Example Records

**Known Model:**
```json
{
  "name": "EV9",
  "brand_id": "...",
  "enrichment_source": "known_dataset",
  "enrichment_confidence": 1.00,
  "enrichment_notes": "Data from curated database",
  "price_from_nok": 749900,
  "range_wltp_km": 563,
  ...
}
```

**AI-Generated Model:**
```json
{
  "name": "Seal U",
  "brand_id": "...",
  "enrichment_source": "ai_generated",
  "enrichment_confidence": 0.82,
  "enrichment_notes": "AI-generated with high confidence. Price and range verified for Norwegian market 2025.",
  "price_from_nok": 549900,
  "range_wltp_km": 500,
  ...

```

**Fallback Model:**
```json
{
  "name": "Unknown Model",
  "brand_id": "...",
  "enrichment_source": "ai_generated",
  "enrichment_confidence": 0.30,
  "enrichment_notes": "Generic fallback data - OpenAI API not available. Values are estimates and should be manually verified.",
  "price_from_nok": 500000,
  "range_wltp_km": 400,
  ...

```

### Querying by Source

```sql
-- Get all AI-generated models
SELECT * FROM models
WHERE enrichment_source = 'ai_generated';

-- Get low-confidence models needing review
SELECT * FROM models
WHERE enrichment_confidence < 0.7
ORDER BY enrichment_confidence ASC;

-- Get models by source distribution
SELECT enrichment_source, COUNT(*)
FROM models
GROUP BY enrichment_source;
```

## 10. LIMITATIONS & FUTURE IMPROVEMENTS

### Current Limitations

1. **API Dependency**
   - Requires OpenAI API key for best results
   - Fallback is generic and low-quality

2. **AI Hallucination Risk**
   - AI may provide inaccurate specs
   - Always requires admin review
   - Confidence score helps prioritize

3. **Norwegian Market Focus**
   - Prices may not reflect all regions
   - Availability may vary

4. **Trim Level Coverage**
   - AI may not know all trim variants
   - May miss special editions

### Future Enhancements

1. **Multiple AI Providers**

   - Keep both AI and manual versions

5. **Automatic Re-enrichment**
